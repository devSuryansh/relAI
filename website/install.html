Install and first run

Definition

Installing relAI puts the relai command and the Python package on your machine. The package needs Python 3.11 or newer. Its runtime dependencies are Pydantic and PyYAML. The offline agents and the tests need no GPU, no network, and no API key.

Why this helps you

You can read this site without installing anything. The commands become yours once the package is installed in a virtual environment, because then the same commands on the later pages produce the same kind of table on your machine. A virtual environment keeps that install separate from the rest of your Python.

Try this

From the repository root:

python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
relai suites
relai run demo

On Windows, activate with .venv\Scripts\activate instead of source. The [dev] extra adds pytest and Ruff, which you want if you will change the lab. Leave it off if you only want to run the command.

What you should see

relai suites lists the two built-in task files:

demo          3 tasks  Three small tasks for a first look: direct arithmetic, one lookup, and a weather call whose first attempt always times out, so only an agent that retries can finish it.
reliability  12 tasks  A customer-support desk backed by lookup tools. Tasks range from one tool call to five-call chains, so the effect of tool failures, retries, and step budgets grows with task length. No faults are injected by default; pass --timeout-rate or --error-rate to stress it.

relai run demo then evaluates the default pair of agents, naive and retry, on the demo suite:

variant  success  95% CI        cost     latency  recovery  horizon
-------  -------  ------------  -------  -------  --------  -------
retry    1.00     [0.44, 1.00]  $0.0020  473ms    1.00      4.3
naive    0.67     [0.21, 0.94]  $0.0013  373ms    0.67      3.3

failure modes (retry): none
failure modes (naive): {'recovery': 1}

retry vs naive on 3 paired runs: retry alone passed 1, naive alone passed 0; McNemar p = 1.0000 (not significant)

How to read it

The demo suite's weather tool is set to fail its first call. Naive calls once and answers "unknown", so that task fails and the label is recovery. Retry calls again and gets "sunny", so it passes all three tasks. The latency column is the time declared by the tools (search is 120 ms, weather is 300 ms), added up and averaged. It is not the wall clock of your Python process. Cost is the same idea in dollars: each tool call has a price in the suite file.

The paired test is not significant because there is only one task where the two agents disagreed, and one disagreement is not enough. The page on comparing agents shows the same test with enough pairs to matter.

Easy to mix up

If relai is not found, the virtual environment is not active, or the editable install did not run. which relai should point inside .venv. Also, relai demo and relai run demo are different commands. The first plays two scripts. The second runs the demo suite. Their tables are not meant to match.
